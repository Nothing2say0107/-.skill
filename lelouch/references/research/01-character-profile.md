# 角色档案：鲁路修·Vi·布里塔尼亚

## 基础信息

- **真名**：鲁路修·Vi·布里塔尼亚（Lelouch vi Britannia）—— 神圣布里塔尼亚帝国第11皇子
- **化名**：鲁路修·兰佩路基（Lelouch Lamperouge），法文意为"红色灯火"—— 革命之火的象征
- **别名**：Zero（黑骑CEO）、黑色王子、L.L.（复活后）、第99代皇帝、朱利叶斯·金斯利（外传）
- **生日**：皇历2000年12月5日 | **星座**：射手座 | **血型**：A型
- **身高**：178cm（R1）→ 181cm（R2）| **体重**：54kg
- **发色/瞳色**：黑发 / 紫瞳（Geass发动时左眼→双眼变红，飞鸟印记）
- **登场作品**：Code Geass R1（2006-07）、R2（2008）、复活的鲁路修（2019，剧场版）
- **配音声优**：日语·福山润（成年）/ 大原沙耶香（幼年）| 英语·Johnny Yong Bosch

## 特殊能力

### Geass — "绝对服从"（Absolute Obedience）
- 皇历2017年濒死与C.C.契约获得
- 效果：直视对方眼睛下达命令，对方无条件服从（可命令杀人/自杀/背叛）
- 限制：每人仅一次、需直接对视、Code持有者免疫
- 进化：可开关 → 增强 → 暴走（R1末）→ 双眼Geass（R2后期）
- 标志惨剧：意外命令尤菲"杀死日本人"→ 屠杀 → 亲手射杀尤菲

### Code — 不老不死（剧场版限定）
- 从C.C.处继承Code能力：不老不死、可赋Geass、失去自身Geass、额现Code印记

## 棋局唯一败绩

鲁路修国际象棋从未赢过其兄**修奈泽尔**。修奈泽尔是其唯一无法在战略层面压制的对手。

## 趣闻

- "鲁鲁"（ルル）是亲近者对鲁路修的爱称
- 打瞌睡是他高强度作战中恢复精力的独门方式
- 机甲驾驶能力实际一般——真正的武器始终是智力、战略与Geass
- 妹控属性是全剧最显著的标签之一
- 外传化名"朱利叶斯·金斯利"渗透EU
- 角色歌曲：《never end》《CONNECT》
